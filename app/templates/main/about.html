About Prosno.io

Making question paper generation effortless for educators

Our Mission

Prosno.io is dedicated to simplifying the process of creating professional MCQ question papers for teachers, coaching centers, and educational institutions. We believe that educators should spend more time teaching and less time on administrative tasks like formatting question papers.

What We Offer

  • Professional two-column layout papers
  • Full Bengali language and numeral support
  • OMR-style answer options
  • Separate student and teacher copies
  • Instant Microsoft Word download
  • Comprehensive question bank

Technology

Our platform is built using modern web technologies including Python Flask for the backend, python-docx for document generation, and a responsive frontend that works on all devices. We use SQLite/PostgreSQL for secure data storage and implement industry-standard security practices.

Open Source

The core question paper generation logic is based on an open-source project and is available under the MIT license. We believe in giving back to the community and welcome contributions from developers worldwide.
